# Bookmark Manager Roadmap

A practical roadmap for improving Mona's bookmark manager.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search & filter bookmarks | 🚀 | High |
| Management | Edit a bookmark | 🚀 | High |
| Organization | Tags or folders | 🚀 | Medium |
| Data portability | Import & export bookmarks | 🚀 | Medium |
| Data integrity | Duplicate slugs on re-add | 🐞 | Medium |
| Validation | Empty-URL validation | 🐞 | High |
| Persistence | Bookmarks lost when localStorage is cleared | 🐞 | Low |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs can occur when a bookmark is re-added — priority: medium
- ⚠️ Empty URLs may not be validated before saving — priority: high
- 💾 Bookmarks can be lost if browser localStorage is cleared — priority: low
